# 基于RAG与大语言模型的商业智能分析对话系统 — 完整处理流程架构

## 系统概述

ChatBI 是一个面向商业数据分析场景的智能对话系统，采用 RAG（检索增强生成）架构，
将结构化知识库（商业术语库、SQL示例库、数据库Schema）与半结构化知识库（文档知识库）
相结合，通过语义检索增强大模型的生成能力，实现自然语言到数据分析的全链路智能处理。

系统采用"双轨共享"架构：SQL轨道（结构化数据查询）与文档轨道（PDF文档问答）
共享对话管理层、术语库和输出层，在检索、增强、生成阶段各自独立处理。

## 双轨共享架构：组件可用性矩阵（COMPONENT_MATRIX）

```
                    术语库(共享)  SQL提示词   SQL示例库   分析提示词   预测提示词   可视化
  PDF(文档轨道)：      ✅          ❌          ❌          ❌          ❌          ❌
  Excel(SQL轨道)：     ✅          ✅          ✅          ✅          ✅          ✅
  CSV(SQL轨道)：       ✅          ✅          ✅          ✅          ✅          ✅
  Database(SQL轨道)：  ✅          ✅          ✅          ✅          ✅          ✅
```

术语库是唯一跨轨道共享的知识源。SQL轨道注入完整字段（word+description+sql_mapping），
文档轨道注入裁剪字段（word+description，过滤sql_mapping避免干扰文档问答质量）。

## 9种意图 × 双轨道的完整处理路径

```
用户查询
    │
    ▼
┌─────────────────────────────────────────────────────────┐
│  意图检测（QueryRewriter._detect_intent）                │
│  + 数据源类型路由（ds_type → 轨道选择）                   │
└─────────────────────────┬───────────────────────────────┘
                          │
         ┌────────────────┼────────────────┐
         ▼                ▼                ▼
    [ds_type=PDF]    [ds_type=DB/Excel/CSV]
         │                │
         ▼                │
    所有意图统一           │
    → DOCUMENT_QA         ├──── fact_query ──────────┐
    → 文档轨道            ├──── statistical_analysis ─┤
         │                ├──── comparison_analysis ──┤→ SQL轨道
         ▼                ├──── trend_analysis ───────┤
    术语库(裁剪版)        ├──── prediction ───────────┘
    + PDF文档块检索        │
    + LLM文本生成          ├──── term_explanation ────→ 直接回答
    + 溯源标注             ├──── ambiguous_query ─────→ (RAG检索术语/文档
                          └──── irrelevant_query ────→  + LLM生成回答)
```
